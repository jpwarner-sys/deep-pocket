# Deep Pocket

A rhythm trainer for bass practice. Nine voices, 18 grooves, a 32-bar arranger
with chord changes, and a sampled room kit (3 velocity layers, 2 round-robins
per voice) rendered offline and embedded, so it works with no network after the
first load.

Everything runs in the browser — Web Audio synthesis plus the sampled kit, a
lookahead scheduler with swing and per-groove micro-timing, and a bass voice that
follows the chord changes so you can play along or mute it and hold the line
yourself.

Saved setups live in this browser's local storage. Nothing is sent anywhere.

Open `index.html`, or add the hosted page to your Home Screen — it installs
standalone, no browser chrome.
